📋 Testing Instructions

  1. Start the API: Make sure your FastAPI server is running on http://127.0.0.1:8000
  2. Register User: Enter email and password, click "Register & Send OTP"
  3. Check Email: Look for OTP in your email inbox (or check server logs for the OTP)
  4. Verify OTP: Enter the received OTP code and verify
  5. Test Login: Login with your verified credentials
  6. Forgot Password: Test password reset flow with reset emails
  7. Protected Route: Test authenticated endpoints
  8. OAuth Testing: Test Discord and Google login integrations
